# Sales-Data_Analysis-Python
Sales Data Analysis Project using Python, Pandas, Matplotlib, and Seaborn# Sales Data Analysis Project

## Project Overview

This project analyzes Walmart sales data using Python.

The analysis includes:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Sales Trend Analysis
- Top Performing Stores
- Holiday Sales Analysis
- Correlation Analysis

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Project Steps

1. Import Libraries
2. Load Dataset
3. Data Cleaning
4. Handle Missing Values
5. Exploratory Data Analysis
6. Data Visualization
7. Business Insights

---

## Key Insights

- Holiday weeks increase sales.
- Some stores consistently outperform others.
- Seasonal trends affect revenue.
- External factors slightly impact sales.
